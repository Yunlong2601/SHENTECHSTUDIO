背景与问题

当前痛点

据用户调研数据显示，78% 的职场人士同时使用 3 个以上日历工具（企业微信、Google 日历、Outlook、Notion 等），导致以下核心问题：

  • 信息分散：日程散落在多个平台，缺乏统一视图，用户需要反复切换工具查看当天安排。
  • 冲突频发：手动比对多个日历极易遗漏时间冲突，平均每人每月遭遇 3.2 次日程冲突。
  • 排程低效：调整一次会议往往需要来回检查 3-5 个参与者的空闲时间，沟通成本高。
  • 遗忘风险：42% 的用户曾因未及时同步日程而错过重要会议或截止日期。

解决思路

「智能日程助手」通过接入主流日历 API 实现多源聚合，基于 AI 模型自动识别冲突并推荐最优排程方案，让用户在一个界面上完成所有日程管理操作，减少碎片化带来的时间和精力损耗。

目标与非目标

项目目标

  • 支持至少 5 种主流日历平台的双向同步
  • AI 冲突检测准确率 ≥ 95%
  • 首次打开到完成首个日程创建 ≤ 2 分钟
  • 用户在单一视图下查看当周全部日程
  • 一键智能排程：30 秒内生成最优方案
  • 支持团队协同排程（≥ 3 人）
  • iOS / Android / Web 三端同步

非目标（v1 不做）

  • 不实现独立的视频会议系统
  • 不包含项目管理看板功能
  • 不支持离线模式下的智能排程
  • 不处理与财务/报销系统的集成
  • 不做企业内部组织架构管理
  • 不包含语音助手交互
  • 不实现自定义 AI 模型训练

交互流程说明

以下为 核心用户路径——从首次打开到完成一次智能排程的完整操作流。

  1. 账户初始化：用户首次打开 App，进入引导页选择需要接入的日历平台（Google/Outlook/企业微信等），逐一完成 OAuth 授权。系统在后台拉取并合并所有来源日程，预计耗时约 90 秒。
  2. 查看统一视图：授权完成后自动跳转「今日」视图，所有来源的日程以不同颜色圆点标记来源，按时间线排列。用户可左右滑动切换日期、点击顶部标签切换日/周/月视图。
  3. 手动创建日程：点击右下角 FAB「+」按钮，进入创建表单。填写标题、时间、地点、参与人（支持搜索通讯录），点击「创建」后同步至对应日历平台。
  4. 冲突检测触发：当新创建的日程与已有日程时间重叠时，系统即刻弹出红色冲突提示卡片，展示冲突的日程详情并提供「调整时间」「忽略」「取消新日程」三个选项。
  5. AI 智能排程：用户点击底部「智能排程」Tab，进入待办列表页。勾选当日待处理事项后点击「生成方案」，AI 在 10 秒内返回带时间块的排程建议，用户可直接确认或拖拽微调。
  6. 团队协同：在创建日程时添加多位参与人，系统实时比对参与人忙闲状态。若存在冲突，高亮不可用时段并推荐最近可用时间，一键发送邀请。
  7. 提醒与后续：日程到期前，App 根据用户历史行为（如通常提前 10 分钟查看）智能推送通知。日程结束后自动归档，并在周报面板中计入统计分析。

验收标准

非功能需求

⚡

性能

  • App 冷启动 ≤ 1.5 秒，热启动 ≤ 0.5 秒
  • 日历视图渲染 6 个月数据 ≤ 500ms
  • 后台同步资源占用 CPU ≤ 5%，内存 ≤ 80MB
  • 支持 ≥ 10 万条日程数据无卡顿
  • API 响应时间 P95 ≤ 200ms
🔒

安全

  • 所有日历平台接入使用 OAuth 2.0，不存储明文密码
  • 数据传输全程 TLS 1.3 加密
  • 日程数据在服务端 AES-256 加密存储
  • 符合 GDPR / 个保法对用户数据删除权的要求
  • 登录态敏感操作需二次验证（如删除全量日程）
📱

兼容性

  • iOS 15+ / Android 11+ / Web（Chrome、Safari、Edge 最新 2 个大版本）
  • Apple Watch 独立应用（查看当天日程 + 快速提醒）
  • 屏幕尺寸适配：320px – 2560px
  • 支持系统级暗色模式
  • VoiceOver / TalkBack 无障碍适配
