## Localization rules

1. Chinese is the source language: `zh_CN`.
2. English is the first target language: `en`.
3. Use stable keys such as `menu.start` and `module.trace_beam`.
4. Translate each feature when it is added.
5. Keep English UI containers flexible because English text may be longer.
6. Preserve placeholders such as `%d`, `%s`, and `{name}`.
7. Do not reintroduce the placeholder name `Star Quest`.
