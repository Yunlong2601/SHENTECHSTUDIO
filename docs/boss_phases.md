# Boss phase state machines

## 1. Folded Regent
- Phase 1: Fold arena into triangular sectors.
- Phase 2: Rotate safe lanes and force movement.
- Phase 3: Collapse safe zones into a final circuit.

## 2. Conductor Array
- Phase 1: Spawn linked nodes.
- Phase 2: Nodes synchronize into timed pulses.
- Phase 3: Break node formation to open the core.

## 3. Archive Zero
- Phase 1: Copy one player module.
- Phase 2: Corrupt pickups and reroute enemies.
- Phase 3: Alternate between copied module and original attack pattern.
