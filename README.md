# Geometry Breakout / 名子理

A chinese-first, bilingual-ready top-down arena servival lite prototype for TapTap Maker.

- Source language: zh_CN
 - Translation target: en
- Platform: TapTap Maker

The current prototype is focused on verifying the bilingual ui; the next milestone is a playable combat loop with one geometric chasse, one arena, three modules, and timed waves.
