# P7 Complete — Character Polish: Smooth Turn, Hit Flash, Idle Bob, Weapon Orbit VFX (2026-08-04 night)

### 3. Idle Bob
- When speed < 15 px/s: sine-wave vertical oscillation ±2.5px at 2.2 rad/s
- Phase accumulates smoothly, resets to 0 when moving

- Diamond color matches weapon definition color (cyan=blade, green=bow, purple=staff, orange=blunt, red-orange=crossbow, gold=thrown)
- Widgets created/destroyed lazily as weapons are equipped/unequipped (via the shop P6)
- `character.destroy()` properly cleans up all orbit widgets
